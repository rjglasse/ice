# Task mapping 2025 -> 2026

Tasks are edited between years, so week N of 2026 is not always the same content as
week N of 2025. Each `task-N.md` here is generated by

```bash
python3 scripts/task_diff.py task-N
```

from the 2025 README (first local clone) and the 2026 README (first local clone, or the
`inda-master` template before repos exist). Exercises are matched by title similarity.
Edit the `comparable` column by hand (`yes` / `changed` / `no`) and add notes; the file is
not regenerated once it exists. `compare.py` prints the yes/changed/no counts next to the
metrics so the reader knows how much the task moved.

Whole-task metrics (commits, issues, closing references per student) remain the unit of
comparison. Where a task changed a lot, use `compare.py task-N --baseline-task task-M` to
compare against the closest 2025 task instead, and say so in the notes here.

Known so far:

| 2026 task | 2025 task | status |
|---|---|---|
| task-1 | task-1 | identical (5 exercises + 2 warmups) |
| task-2 | task-2 | reworked: 6 exercises vs 9; 2.3/2.4/2.6 match old 2.6/2.7/2.8 |
